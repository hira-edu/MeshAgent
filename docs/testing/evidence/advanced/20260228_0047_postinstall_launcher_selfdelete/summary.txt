FEATURE: post-install launcher self-delete
DATE_UTC: 2026-02-27T19:47:30Z

IMPLEMENTATION
- Native installer now supports explicit launcher cleanup flag.
- New switch: --cleanup-launcher (also accepts --cleanup-launcher=0|1).
- On successful -fullinstall, native path schedules deletion of the launcher binary after process exit.
- Safety guards: cleanup is skipped when running from installed service binary path or install-root path.
- GUI interactive install/update path now always passes --cleanup-launcher on Windows.

CODE CHANGES
- meshcore/agentcore.c
  - Added cleanup flag parse + post-install trigger.
  - Added launcher cleanup scheduler and path safety checks.
- modules/interactive.js
  - _install() adds --cleanup-launcher on Windows flows.
