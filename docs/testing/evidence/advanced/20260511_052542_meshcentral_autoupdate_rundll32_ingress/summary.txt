# MeshCentral Auto-Update Rundll32 Ingress Evidence

Date: 2026-05-11

Scope:
- Verify that MeshCentral self-update activation from an already-installed agent converges through the rundll32 lifecycle SSOT path.
- Verify that the update transaction host DLL is staged from the update package, not copied from the installed DLL.

Source changes:
- `meshservice/ServiceMain.c`
  - Added narrow `-fullupdate` / `-fupdate` self-update ingress.
  - The ingress parses `--update-source` / `--update-dll` and immediately delegates to `MeshRundll32_LaunchLifecycleHostW(MESH_RUNDLL32_LIFECYCLE_ACTION_UPDATE, ...)`.
  - It does not perform file replacement, service registration, validation, rollback, or fallback lifecycle work.
- `meshservice/rundll32_contract.c`
  - Removed the update-specific path that copied the installed `diagsvc.dll` as the lifecycle host.
  - Update now stages the lifecycle host DLL from the update package through `Stealth_StageSvchostDllForLifecycleHost`.
