ROOT_CAUSE_ANALYSIS
- GUI launch "error=127 / specified procedure could not be found" was coupled with two deterministic installer flow defects:
  1) Repeated ACL hardening on every installer log write caused severe/full stalls in install child process.
     - Confirmed by dump: MeshService64 -> Stealth_LogInstallEvent -> Stealth_EnsureLogDirectory -> SetNamedSecurityInfoW (ntmarta).
  2) WMI restart-subscription creation could block indefinitely during PutInstance RPC.
     - Confirmed by dump: MeshService64 -> StealthResilience_CreateWmiRestartSubscription -> fastprox!PutInstance.
- Non-admin GUI relaunch path also surfaced confusing shell UI errors; launch telemetry showed ERROR_CANCELLED (1223).

FIXES_APPLIED
- meshservice/stealth_installer.c
  - Added cached, fast log-directory ensure path to avoid repeated DACL re-application per log event.
  - Reordered restart persistence flow: create/verify restart task first; only attempt WMI subscription when task persistence is not healthy.
  - Set restartTaskHealthy=true when restart task is created.
- meshservice/ServiceMain.c
  - Non-admin runas launch now uses SEE_MASK_FLAG_NO_UI to suppress ambiguous shell popups.
  - GUI error message for ERROR_CANCELLED now explicitly indicates UAC prompt declined/unavailable.
- meshservice/MeshService-2022.vcxproj
  - StealthLab|x64 linker UAC level set to RequireAdministrator for auto-elevation prompt on launch.
