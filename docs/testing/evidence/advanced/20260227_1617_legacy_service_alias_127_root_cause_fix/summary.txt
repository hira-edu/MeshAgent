Issue: GUI update/uninstall failures with error 127 ("The specified procedure could not be found").

Root cause:
- Stale legacy svchost service alias `DiagHostSvc` remained installed under `C:\ProgramData\WinDiagnosticHost`.
- That legacy service had `Parameters\ServiceDll` but missing `Parameters\ServiceMain`, which causes SCM startup failure 127.
- Current native install/update/uninstall paths target `WinDiagnosticHost` and previously did not proactively remove this stale legacy alias.

Code fix:
- File: meshservice/stealth_installer.c
- Added native legacy cleanup path `Stealth_CleanupLegacyServiceAlias()`.
- Cleanup now runs at start of:
  - Stealth_PerformCompleteInstallation()
  - Stealth_PerformUpdate()
  - Stealth_PerformCompleteUninstallation()
- Cleanup behavior:
  - Detects legacy alias `DiagHostSvc` only when its ServiceDll is rooted under `C:\ProgramData\WinDiagnosticHost`.
  - Removes legacy service registration, stop/recovery/runkey/task/firewall artifacts, and stale files/dirs.
  - Logs structured `[LEGACY]` events to installer log.
