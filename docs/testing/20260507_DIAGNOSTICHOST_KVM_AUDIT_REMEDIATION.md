## 2026-06-27 Schoolyear Reconnect Session-Selector Correction

- Additional root cause: `kvm_relay_select_session_id(-1)` preferred any queryable session named `Console` before checking whether a different WTS session was currently `WTSActive`. The observed Schoolyear flow uses `schoolyear-exams-service.exe` `RpcLogoff`, logs off/disconnects the original interactive session, then creates a replacement interactive session. A stale queryable Console session could therefore win a fresh MeshCentral reconnect after the Schoolyear transition, leaving KVM attached to the wrong session even though a valid active replacement session existed.
